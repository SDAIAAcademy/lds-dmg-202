# البيانات الوصفية وكتالوجات البيانات وتتبع أصل البيانات

Metadata, Catalogues and Lineage

مسار التنفيذيين والقادة · أكاديمية سدايا · LDS-DMG-202 · المستوى 200

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

يشغّل المشاركون كتالوج بيانات مفتوح المصدر على قاعدة بيانات اصطناعية ومخزن ملفات لجهة افتراضية. فيستخلصون البيانات الوصفية الفنية، ويضيفون ما لا تستطيع الآلة إضافته (مصطلحات القاموس والملاك والتصنيفات)، ويقيسون عدد الأوصاف التي صاغتها الآلة وتحتاج إلى تصحيح، ويقدّرون أثر تغيير ما من خلال تتبع أصل البيانات، ويعدّون سجلات لكتالوج وطني أو كتالوج للبيانات المفتوحة.

**الصيغة:** ورشة عمل: يومان مع مختبرات، ومهمة متابعة قصيرة

**صفحة المقرر:** https://sdaiaacademy.github.io/lds-dmg-202/

## نواتج التعلم

| | نواتج التعلم | المستوى | الدليل |
|---|---|---|---|
| LO1 | يهيئ الاستخلاص المجدول للبيانات الوصفية الفنية من قاعدة بيانات ومخزن ملفات، باستخدام نسخة معدة من كتالوج البيانات ومصادر اصطناعية | Applied | فهرسة كل جدول وملف مع مخطط البيانات وإحصاءات التنميط |
| LO2 | يعدّ مصطلحات القاموس ويربطها بالأعمدة والملاك والتصنيفات، استنادًا إلى 30 عمودًا وملاحظات مشرفي البيانات | Applied | 15 مصطلحًا معتمدًا ومرتبطًا |
| LO3 | يقيس معدل الخطأ في أوصاف الأصول التي صاغتها الآلة عند مراجعة مشرفي البيانات لها، على 40 مسودة وباستخدام سلم تقدير | Applied | سجل قبول أو تعديل أو رفض يبيّن أكثر أنواع الأخطاء شيوعًا |
| LO4 | يحلل الأثر اللاحق لتغيير في مخطط البيانات باستخدام تتبع أصل البيانات المسجل، استنادًا إلى أحداث تتبع أصل البيانات وطلب تغيير | Applied | مذكرة أثر تسمي التقارير والملاك المتأثرين، مع قرار بالمضي أو التوقف |
| LO5 | يعدّ سجلات لمجموعات البيانات بمفردات معيارية لكتالوج خارجي، استنادًا إلى خمس مجموعات بيانات مفهرسة والحقول التي يشترطها الكتالوج المستهدف | Applied | خمسة سجلات تتضمن الترخيص وجهة الاتصال وتجتاز أداة التحقق في الكتالوج المستهدف |

## الأدوات

كل سطر قدرة، والأمثلة قابلة للتبديل.

- **كتالوج بيانات مفتوح المصدر:** OpenMetadata, DataHub
- **أحداث تتبع أصل البيانات:** OpenLineage مع Marquez, خاصية تتبع أصل البيانات المدمجة في كتالوج البيانات
- **مفردات البيانات الوصفية لمجموعات البيانات:** W3C DCAT, Dublin Core
- **نموذج لغوي للصياغة:** نموذج مفتوح الأوزان يُشغَّل محليًا, أي نموذج مستضاف معتمد
